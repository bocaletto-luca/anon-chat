# AnonChat A front-end–only, anonymous multi-user chat application offering real-time public and private conversations. User identities are represented by a unique ID, nickname, and password, with all chat data stored in JSON files on the server. No backend framework is required—just a static file server capable of handling HTTP GET, PUT, and HEAD requests for `.json` files. --- ## Features - Anonymous registration and login (ID, nickname, password) - Global public chat room - One-on-one private chats with online users - Real-time message updates via lightweight polling - Automatic creation of required JSON storage files - Responsive, modern UI optimized for desktop and mobile - SEO-friendly meta tags and Open Graph/Twitter Card integration --- ## File Structure ```text anon-chat/ ├── index.html # Single-page application (HTML, CSS, JS) ├── users.json # Registered user data ├── global.json # Public chat message history ├── online.json # Online user presence list └── convs_.json# Per-user private conversation histories ``` --- ## Setup 1. Place the entire `anon-chat` directory on any static file server that supports: - HTTP `GET` for reading JSON - HTTP `PUT` for writing JSON - HTTP `HEAD` for existence checks 2. Ensure write permissions are granted on the directory so that JSON files can be created and updated at runtime. 3. Access `index.html` through the server URL (e.g., `https://example.com/anon-chat/index.html`). --- ## Usage 1. **Register** - Enter a unique nickname and password - A new user record is appended to `users.json` 2. **Login** - Authenticate with nickname and password - User ID is stored in `localStorage` - User appears in `online.json` 3. **Global Chat** - Messages posted to `global.json` via PUT - Polling interval refreshes public chat view 4. **Private Chat** - Click an online user to open a private chat window - Conversation files `convs_.json` and `convs_.json` are initialized if missing - Private messages are stored in both users’ conversation files --- ## Configuration - **Polling Intervals** - Global chat refresh: 1.5 s - Online list refresh: 2 s - Private chat refresh: 1 s - **JSON Initialization** - `users.json`: `{ "users": [] }` - `global.json`: `{ "messages": [] }` - `online.json`: `{ "online": [] }` - `convs_.json`: `{ "privateChats": {} }` - **UUID Generation** - Version 4 UUIDs generated in-browser for user IDs and message IDs --- ## Meta & SEO - ``, `<meta name="description">`, and `<meta name="keywords">` for search engines - Open Graph and Twitter Card tags for rich social sharing - Canonical link to the GitHub repository: ``` https://github.com/Bocaletto-Luca/anon-chat ``` --- ## License This project is released under the GPL v3 License. © 2025 Luca Bocaletto
